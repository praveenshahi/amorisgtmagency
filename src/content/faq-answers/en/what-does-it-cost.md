Pricing is scoped per engagement, so there is no published rate card.

The two variables that move it are which model you pick and how much of the stack already exists. Done With You leverages your infrastructure and tools, which usually narrows the scope. Done For You includes the full stack design and setup, so it is the larger engagement.

Start with the audit. It is short, it gives you a written map of the problem either way, and it is the only honest basis for a number.
